# Contributor License Agreement

**This file is not the authoritative text.** The document contributors actually sign lives in a
gist:

> **https://gist.github.com/HwangTaehyun/fd42a3ed0bb566d176a273d4fd339159**

CLA Assistant reads that gist directly and surfaces it in the PR comment. It never reads the file
in this repository.

## Why there is no copy here

The same document in two places drifts apart. You could edit the repository copy and the document
people sign would stay unchanged — and later "which one did they agree to?" becomes a real
dispute. **There must be exactly one thing being signed.**

## To change the terms

Edit the gist. But note — **when the gist changes, every existing signer has to sign again on
their next PR.** That is true even for a typo. Proceed carefully.

## Summary

The short version of what signing means is in [`CONTRIBUTING.md`](CONTRIBUTING.md); the full text
and the reasoning behind it are in the gist above.
