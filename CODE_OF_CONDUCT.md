# Code of Conduct

## Our pledge

Everyone taking part in this project — regardless of age, body size, disability, ethnicity, sex
characteristics, gender identity and expression, level of experience, nationality, personal
appearance, race, religion, or sexual orientation — should be able to do so free of harassment.

## Specific to this repository

Beyond the usual norms for a technical repository, this project handles a **personal knowledge
database**.

- **Do not quote anyone else's note content.** In logs and screenshots you attach to issues, PRs,
  and discussions, redact document titles, entity names, and paths. What is needed to reproduce a
  bug is usually the structure, not the content.
- **Do not paste secrets.** Leave `.env` out entirely, and if a token does slip in, closing the
  issue is not enough — **rotate the token**.
- If reproduction data containing real names is genuinely needed, send it privately through the
  [security reporting path](SECURITY.md).

## Unacceptable behaviour

Harassment, personal attacks, discriminatory remarks, sexualized language or advances, publishing
others' private information, and other conduct that would be inappropriate in a professional
setting.

## Reporting

Write to thbeem94@gmail.com. Reporters' identities are not disclosed.
Security vulnerabilities go through [`SECURITY.md`](SECURITY.md) instead of here — please do not
open a public issue for those.
